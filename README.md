# SmartTools Complete Website Package

This ZIP combines the newer multi-category dark-theme website with the previous core browser tools, so no important earlier files are lost.

## Included files
- `index.html` — category homepage
- `image.html`, `pdf.html`, `audio.html`, `other.html` — separate category pages
- `tools.html` — working core image/PDF tools
- `app.js` — core browser-side processing
- `style.css` — dark responsive theme
- `privacy.html`, `about.html`, `contact.html` — starter information pages

## Upload to your existing GitHub repository
1. Extract this ZIP.
2. Upload every file inside the `SmartTools_Complete` folder to the root of your repository (not the ZIP itself).
3. Replace files when GitHub asks, and commit the changes.
4. GitHub Pages should redeploy automatically.

## Core tools included
- Images to PDF
- Image compression with a desired KB target (best-effort; exact size cannot always be achieved)
- Image resizing to custom width and height
- Merge PDFs
- PDF pages to PNG

## Important
The category pages list a broader roadmap, but only the tools in `tools.html` are implemented in this package. Do not advertise the planned tools as functional until implemented and tested. AdSense approval and earnings are not guaranteed. Add accurate policy/contact pages and original useful content before applying.
