# SmartTools — Photo & PDF Tools

A mobile-friendly static website starter.

## Tools included
- Images to PDF
- Image compressor (exports JPEG)
- Image resizer (exports PNG)
- Merge PDFs
- PDF pages to PNG

## Preview
Extract the ZIP and open `index.html` in a modern browser. An internet connection is required for the PDF libraries and Google Fonts loaded from CDNs.

## Publish free using GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose deploy from branch, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to show your website address.

## Before applying for AdSense
- Add a real Privacy Policy, About, Contact and Terms pages.
- Write useful original content and explain each tool.
- Test all tools on phones and computers with different file sizes.
- Replace the ad placeholder with AdSense code only after approval.
- AdSense approval and earnings are not guaranteed.
- Keep ads clearly separate from download/process buttons; follow Google's policies.
- This project uses third-party CDNs for PDF libraries and fonts. Review dependencies before production.
- PDF-to-image export starts one download per page; the browser may block multiple downloads.
- Files are processed in the browser by the included tools, but external scripts/fonts are loaded from CDNs.
